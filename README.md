## English

Open Burning Suite creates, burns, copies and verifies CD, DVD and Blu-ray discs and disc images. It includes guided workflows for data, audio, video and game discs.

### Install on Windows

1. Open [Releases](https://github.com/QianLieXian/OpenBurningSuite-chinese/releases) and download the **Windows amd64 Setup.exe** asset. One installer contains all four interface languages; you do not need a separate language pack or portable ZIP.
2. Run the installer and select **English**, **Русский**, **简体中文** or **日本語** in the language dialog. This sets the initial application language.
3. Finish installation and open Open Burning Suite. The .NET runtime is included.

To change the language later, open **Settings → General → Interface language**, select a language and click **Save Settings**. The interface changes immediately. Your saved preference takes priority over the installation and system language.

**Requirements:** 64-bit Windows 10/11 on an AMD or Intel x64 processor. “amd64” also means “x64”; this release does not contain an ARM64 installer. An optical drive and appropriate device permissions are needed for physical disc operations. Building images from files does not require a drive.

### What you can do

- Burn, copy and verify CD/DVD/Blu-ray media; inspect drive and disc information.
- Build data images with ISO 9660, Joliet, UDF, Rock Ridge or HFS+.
- Work with ISO, BIN/CUE and other supported disc-image formats.
- Create audio discs, use video-authoring wizards and choose gaming presets.
- Verify checksums and encrypt disc images.

**Optional tools:** video transcoding needs FFmpeg; CHD operations need MAME's `chdman`. Install these separately and set their executable paths in Settings if they are not on PATH. These tools are not needed for ordinary data-image creation and disc burning. Physical disc capabilities depend on your drive and media; software cannot add unsupported hardware features.

For detailed workflows, see the [documentation](docs/getting-started.md). [Report a problem](https://github.com/QianLieXian/OpenBurningSuite-chinese/issues) with the application version, selected language, operation and relevant log. Do not include passwords, keys or private disc contents.

<a id="русский"></a>
## Русский

Open Burning Suite — приложение для создания, записи, копирования и проверки CD, DVD, Blu-ray и образов дисков. Пошаговые мастера помогают работать с дисками с данными, аудио-, видео- и игровыми дисками.

### Установка в Windows

1. Откройте [Releases](https://github.com/QianLieXian/OpenBurningSuite-chinese/releases) и скачайте установщик **Windows amd64 Setup.exe**. Один установщик содержит все четыре языка интерфейса. Отдельный языковой пакет или ZIP-архив не нужен.
2. Запустите установщик и выберите **English**, **Русский**, **简体中文** или **日本語**. Выбранный язык будет использован при первом запуске приложения.
3. Завершите установку и откройте Open Burning Suite. Среда выполнения .NET уже включена в установщик.

Чтобы сменить язык позже, откройте **Настройки → Общие → Язык интерфейса**, выберите язык и нажмите **Сохранить настройки**. Интерфейс изменится сразу. Сохранённый выбор пользователя имеет приоритет над языком установщика и системы.

**Требования:** 64-разрядная Windows 10/11 и процессор AMD или Intel с архитектурой x64. Обозначения «amd64» и «x64» означают одну архитектуру. Установщик ARM64 в этот выпуск не входит. Для работы с физическими дисками нужен оптический привод и права доступа к нему. Создавать образы из файлов можно без привода.

### Возможности

- Запись, копирование и проверка CD/DVD/Blu-ray; просмотр сведений о приводе и диске.
- Создание образов с файловыми системами ISO 9660, Joliet, UDF, Rock Ridge и HFS+.
- Работа с ISO, BIN/CUE и другими поддерживаемыми форматами образов.
- Создание аудиодисков, пошаговая подготовка видеодисков и игровые профили.
- Проверка контрольных сумм и шифрование образов дисков.

**Дополнительные инструменты:** для перекодирования видео нужен FFmpeg, для работы с CHD — `chdman` из MAME. Установите их отдельно и укажите пути в настройках, если они недоступны через PATH. Для обычного создания образов данных и записи дисков эти инструменты не требуются. Возможности работы с физическими дисками зависят от привода и носителя.

Подробные инструкции находятся в [документации на английском языке](docs/getting-started.md). Если возникла проблема, [создайте обращение](https://github.com/QianLieXian/OpenBurningSuite-chinese/issues), указав версию приложения, язык, выполняемую операцию и соответствующий журнал. Не публикуйте пароли, ключи и личные данные с дисков.

## 简体中文

Open Burning Suite 是一款用于制作、刻录、复制和校验 CD、DVD、蓝光光盘及光盘镜像的桌面应用。数据、音频、视频和游戏光盘均提供分步向导。

### 在 Windows 上安装

1. 打开 [Releases](https://github.com/QianLieXian/OpenBurningSuite-chinese/releases)，下载 **Windows amd64 Setup.exe** 安装文件。一个安装包包含全部四种界面语言，无需单独下载语言包或便携 ZIP。
2. 运行安装程序，在语言选择窗口选择 **English、Русский、简体中文或日本語**。应用首次启动时会使用所选语言。
3. 完成安装并打开 Open Burning Suite。安装包已包含 .NET 运行时，无需额外安装。

以后可在 **设置 → 常规 → 界面语言** 中选择语言，点击 **保存设置** 后立即生效。用户保存的语言设置优先于安装语言和系统语言。

**系统要求：** 配备 AMD 或 Intel x64 处理器的 64 位 Windows 10/11。“amd64”与“x64”是同一种架构，并非仅支持 AMD 处理器。本次发布不包含 ARM64 安装包。操作实体光盘需要光驱及相应的设备访问权限；从文件制作镜像不需要光驱。

### 主要功能

- 刻录、复制和校验 CD/DVD/蓝光光盘，查看光驱与介质信息。
- 使用 ISO 9660、Joliet、UDF、Rock Ridge 或 HFS+ 文件系统制作数据镜像。
- 处理 ISO、BIN/CUE 等受支持的光盘镜像格式。
- 制作音频光盘，使用视频光盘向导和游戏机预设。
- 校验文件哈希、加密光盘镜像。

**可选工具：** 视频转码需要 FFmpeg；CHD 操作需要 MAME 的 `chdman`。请单独安装；如未加入 PATH，可在设置中指定可执行文件路径。普通数据镜像制作和光盘刻录不依赖这些工具。实体光盘功能取决于光驱及介质能力，软件无法提供硬件本身不支持的功能。

详细操作请参阅[英文文档](docs/getting-started.md)。遇到问题时，请[提交问题反馈](https://github.com/QianLieXian/OpenBurningSuite-chinese/issues)，附上应用版本、界面语言、所执行的操作及相关日志。请勿上传密码、密钥或私人光盘内容。

<a id="日本語"></a>
## 日本語

Open Burning Suite は、CD、DVD、Blu-ray とディスクイメージの作成・書き込み・コピー・検証を行うデスクトップアプリです。データ、オーディオ、ビデオ、ゲーム用ディスクには、手順に沿って操作できるウィザードを用意しています。

### Windows へのインストール

1. [Releases](https://github.com/QianLieXian/OpenBurningSuite-chinese/releases) を開き、**Windows amd64 Setup.exe** をダウンロードします。1 つのインストーラーに 4 言語を収録しているため、言語パックやポータブル版 ZIP を別途ダウンロードする必要はありません。
2. インストーラーを実行し、言語選択画面で **English、Русский、简体中文、日本語** のいずれかを選びます。初回起動時には、この言語が使用されます。
3. インストールを完了し、Open Burning Suite を起動します。.NET ランタイムは同梱されています。

後から言語を変更する場合は、**設定 → 全般 → 表示言語** で言語を選び、**設定を保存** をクリックしてください。すぐに表示が切り替わります。保存した言語設定は、インストール時の選択やシステムの言語より優先されます。

**動作要件：** AMD または Intel の x64 プロセッサを搭載した 64 ビット版 Windows 10/11。「amd64」と「x64」は同じアーキテクチャを指します。今回のリリースに ARM64 用インストーラーは含まれません。実際のディスクを操作するには、光学ドライブとデバイスへのアクセス権限が必要です。ファイルからイメージを作成するだけなら、ドライブは不要です。

### 主な機能

- CD/DVD/Blu-ray の書き込み、コピー、検証と、ドライブ・ディスク情報の表示。
- ISO 9660、Joliet、UDF、Rock Ridge、HFS+ によるデータイメージの作成。
- ISO、BIN/CUE など、対応するディスクイメージ形式の処理。
- オーディオディスクの作成、ビデオディスクウィザード、ゲーム機向けプリセット。
- チェックサムの検証とディスクイメージの暗号化。

**任意の外部ツール：** 動画の変換には FFmpeg、CHD の処理には MAME の `chdman` が必要です。別途インストールし、PATH に登録していない場合は、設定画面で実行ファイルのパスを指定してください。通常のデータイメージ作成やディスクの書き込みには不要です。実際のディスクで利用できる機能は、ドライブとメディアの仕様によって異なります。

詳しい手順は[英語のドキュメント](docs/getting-started.md)をご覧ください。問題が発生した場合は、アプリのバージョン、表示言語、実行した操作、関連ログを添えて[報告してください](https://github.com/QianLieXian/OpenBurningSuite-chinese/issues)。パスワード、鍵、個人のディスク内容は公開しないでください。

## Development / Разработка / 开发 / 開発

The source supports Windows, Linux and macOS; this repository's release workflow deliberately publishes **one Windows amd64 installer**. Use the existing checkout in cloud tasks; creating another Git worktree is unnecessary.

Prerequisites: .NET 8 SDK and the native libraries described in [LINUX.md](LINUX.md) or [macOS.md](macOS.md).

```sh
dotnet restore OpenBurningSuite/OpenBurningSuite.csproj
dotnet build OpenBurningSuite/OpenBurningSuite.csproj -c Release --no-restore
dotnet run --project OpenBurningSuite/OpenBurningSuite.csproj -c Release --no-build

# Language override for testing; does not overwrite saved preferences:
dotnet run --project OpenBurningSuite/OpenBurningSuite.csproj -- --language ja

# Localization integrity and behavior checks:
python scripts/check-localization.py
dotnet run --project tests/Localization.Tests -c Release
```

Use the `.csproj` explicitly: the .NET 8 SDK does not support the repository's `.slnx` solution format. Localization architecture and translation maintenance are described in [docs/localization.md](docs/localization.md).
